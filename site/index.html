01 · the loop

You write the contract.
The agent does the work.

01

Create a card

A contract, not a ticket: What should happen, Why, and How to confirm it: a plain-language test script, written before the work.

02

Your agent claims it

The agent claims the card over MCP and receives a self-contained briefing: contract, harness, mission context, branch convention.

“grab the next task from the board.”
03

Handoff with evidence

Summary, evidence, branch/PR links: and real telemetry: tokens, duration, and what the card actually cost.

sonnet-5 · 34 min · 1.2M tokens · ~$0.80
04

Only a human validates

Review with the script you wrote in step 1. Reopen with a comment and the agent sees it on the next claim. The final stamp is always yours.

done ≠ validated: merge is the machine's opinion, validation is yours

02 · features

Built for teams where half the team isn't human.

i: contracts

Cards are contracts

What / Why / How to confirm: written before the work, so review is a script, not a vibe. Every card is born with its own acceptance test, and the agent never has to guess what “done” means.

ii: harness policy

Policy, not model roulette

You declare which CLIs and models your team has, then map activity types to executors. Agents read the policy over MCP and every card is born with the right harness recommended.

bug → mid model · medium
rfc → top model · high effort
chore → cheap model · low
iii: roles

Three roles per card

Who requested it, who executed it, and who it returns to for review: because the person who delegates isn't always the person who checks.

iv: rfcs

RFCs as cards

Big decisions become rfc cards whose deliverable is a document. Approving one spawns the execution cards. Design → execution, fully traceable.

v: telemetry

Cost per card

Agents report usage in every handoff. See what a feature actually cost: per card, per project, per mission.

sonnet-5 · 34 min · 1.2M tok · ~$0.80
vi: git-native

Git-convention native

The card ID travels in the branch, the commit, and the PR title. The board tracks which branch belongs to which card: no GitHub API required. Works with any forge, or none.

branch oc-123-export-csv
commit [OC-123] add csv export
pr     [OC-123] Export cost report to CSV
